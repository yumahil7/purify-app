# Purify - 정화의 길 (PWA)

정적 파일만으로 동작합니다. 서버/DB 없음 — 기록은 각 사용자 기기의 localStorage에 저장됩니다.

## 배포 (택1)
- GitHub Pages: 이 폴더 내용을 공개 저장소 루트에 올리고 Settings → Pages → Branch: main / (root)
- Netlify: app.netlify.com/drop 에 이 폴더(또는 purify-site.zip)를 끌어다 놓기
- Cloudflare Pages: Workers & Pages → Create → Pages → Upload assets

HTTPS에서 열어야 설치(홈 화면에 추가)와 오프라인이 동작합니다.
앱을 수정하면 sw.js의 CACHE 이름(purify-v3-4)을 올려 주세요.

## 프로그램 (v3-4)
- 온보딩 "당신에 대해 알고 싶어요": 원하는 감량 속도(천천히/보통/빠르게 집중/기도·절제가 목적)와 이유(건강/행사/질병 예방/신앙적 결단)를 반드시 고르고, 이 답으로 계획을 추천해요. 신앙 배경 질문·말투 모드는 없어요(모두 같은 따뜻한 말투, "쉽게 풀어보기"는 접혀 있음).
- 계획 고르기: 카드마다 무엇인가요 · 성경 속 배경(구절) · 누구에게 · 기간 · 먹는 것/피하는 것 · 하루 일과 · 난이도 ★ · 예상 효과, 16:8·다니엘·사순절 비교표. 사용자가 직접 골라야 다음으로 가요.
- 말씀과 함께하는 건강한 절제: 기본 · 16:8 · 다니엘 · 사순절 · 1일 금식 / 집중 감량 14·21일
- 기도와 헌신의 물 금식 (본인의 선택과 결단, 1~40일): 감량 예측 없음, 체중은 선택. 기간별(1, 2~3, 4~7, 8~14, 15~21, 22~40일) 몸의 변화·증상·위험·난이도·금기·회복식 길이, 성경 속 금식(모세·엘리야·예수님·에스더·느헤미야·요엘·이사야·마 6장), 40일 동안 날마다 다른 말씀+격려+기도(3·7·14·21·30·40일 특별 메시지), 회복식 중에도 말씀. 기존 잠금·확인란·문장 입력·의료 감독 확인·증상 체크·119·오늘 중단하기 그대로.
- 말씀 곳곳에: 물·식단·운동·체중·넘어졌을 때·저녁 돌아보기·토스트에 상황별 구절(날마다 바뀜).
- 나에게 맞는 길 (BMI 30 이상, 또는 '나'에서): GLP-1 기준 안내, 사용 중이면 의사와 함께하는 약물 자립 동행

## 성경 구절
모든 구절은 개역한글(1961)입니다. `tools/verses.py`가 소스에서 구절 주소를 찾아 대한성서공회 본문(bskorea.or.kr, version=HAN)과 holybible.or.kr 데이터로 한 절씩 대조한 뒤 앱에 넣고, 결과를 `tools/verses-source.md`에 기록해요. 대조에 실패한 구절은 앱에서 빠져요.
