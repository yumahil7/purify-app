# Purify - 정화의 길 (PWA)

정적 파일만으로 동작합니다. 서버/DB 없음 — 기록은 각 사용자 기기의 localStorage에 저장됩니다.

## 배포 (택1)
- GitHub Pages: 이 폴더 내용을 공개 저장소 루트에 올리고 Settings → Pages → Branch: main / (root)
- Netlify: app.netlify.com/drop 에 이 폴더(또는 purify-site.zip)를 끌어다 놓기
- Cloudflare Pages: Workers & Pages → Create → Pages → Upload assets

HTTPS에서 열어야 설치(홈 화면에 추가)와 오프라인이 동작합니다.
앱을 수정하면 sw.js의 CACHE 이름(purify-v3-3)을 올려 주세요.

## 프로그램 (v3-3)
- 말씀과 함께하는 건강한 절제·단식: 기본 · 16:8 · 다니엘 · 사순절 · 1일 금식
- 집중 감량 14/21일: max(최소 1,200/1,500kcal, TDEE−750), 16:8, 고단백, 매일 30~45분 운동, 끝나면 14일 유지 기간 권유 (BMI 23 미만·임신·18세 미만·섭식장애 잠금)
- 물 단식 (본인 선택, 앱이 권장하지 않음) 1~40일: BMI 25 미만·임신·18세 미만·섭식장애·제1형 당뇨/인슐린 잠금, 3일 초과 상담 확인+문장 입력, 7일 초과 의료 감독 확인, 매일 증상·혈압·혈당 체크, 오늘 중단하기 → 회복식(단식 일수 × 0.45, 최소 1일) → 유지/기본
- 나에게 맞는 길 (BMI 30 이상, 또는 '나'에서): GLP-1 기준 안내, 사용 중이면 의사와 함께하는 약물 자립 동행
