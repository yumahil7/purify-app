# Purify - 정화의 길 (PWA)

정적 파일만으로 동작합니다. 서버/DB 없음 — 기록은 각 사용자 기기의 localStorage에 저장됩니다.

## 배포 (택1)
- GitHub Pages: 이 폴더 내용을 공개 저장소 루트에 올리고 Settings → Pages → Branch: main / (root)
- Netlify: app.netlify.com/drop 에 이 폴더(또는 purify-site.zip)를 끌어다 놓기
- Cloudflare Pages: Workers & Pages → Create → Pages → Upload assets

HTTPS에서 열어야 설치(홈 화면에 추가)와 오프라인이 동작합니다.
앱을 수정하면 sw.js의 CACHE 이름(purify-v3-5)을 올려 주세요.

## v3-5
- 디자인: 가운데 세로 금색 선 제거. 차분한 청록·남색 바탕 + 세이지/올리브 + 크림 글자, 금색은 작은 강조에만. 그림자 부드럽게, 카드 더 둥글게. 물 금식 영역은 은은한 보라로 조화. 글자 대비 WCAG AA 이상 (본문 10.4:1).
- 자가포식 스위치 (16:8 · 1일 금식 · 집중 감량 타이머, 물 금식 경과 시간): 12시간 대사 전환 → 16시간 자가포식 스위치 ON(토스트 + 알림 카드, 새로고침해도 한 번만) → 24시간 활발 → 48시간 더 활발. 단계마다 근거 수준 표시, 다음 단계까지 진행 막대.
- 건강 정보 탭(하단 5칸: 오늘·기록·말씀·건강·나): 자가포식 설명(오스미, mTOR/AMPK/인슐린, 미토파지·단백질 덩어리·소기관·제노파지·리포파지, 혈관·뇌·면역·노화, 근거 수준 + DOI), 항산화·건강 식품 24가지(검색·분류), 해독 주스·효소(정직한 과학, 레시피, 하루 채소·과일 양), 일상 약품·영양제 8가지(권장량·상한·상호작용·의사·약사 상담). 식단의 음식에서 바로 연결.
- 기도와 헌신의 물 금식: 기간은 1 · 3 · 7 · 14 · 21 · 40일만 (숫자마다 성경 속 의미). BMI 18.5 미만 잠금, 정상 체중(18.5~24.9)은 3일까지, BMI 25 이상은 모든 기간(기존 확인 절차 그대로).
- 배경 음악: 재생 목록 「찬송가 경음악」(잔잔한 피아노 · 슈베르트 아베 마리아 선율 편곡)과 「그레고리오 성가」(Salve Regina · Veni Creator · Ave maris stella · Pange lingua · Ubi caritas, 악기만). 순서대로 재생(기본, 3초 크로스페이드)/한 곡 반복, 곡 선택. 성가는 라틴어 가사와 직접 옮긴 우리말을 ♪ 아래 작은 카드와 나 탭에 표시. 출처: `tools/music-sources.md`.

## 프로그램 (v3-4)
- 온보딩 "당신에 대해 알고 싶어요": 원하는 감량 속도(천천히/보통/빠르게 집중/기도·절제가 목적)와 이유(건강/행사/질병 예방/신앙적 결단)를 반드시 고르고, 이 답으로 계획을 추천해요. 신앙 배경 질문·말투 모드는 없어요(모두 같은 따뜻한 말투, "쉽게 풀어보기"는 접혀 있음).
- 계획 고르기: 카드마다 무엇인가요 · 성경 속 배경(구절) · 누구에게 · 기간 · 먹는 것/피하는 것 · 하루 일과 · 난이도 ★ · 예상 효과, 16:8·다니엘·사순절 비교표. 사용자가 직접 골라야 다음으로 가요.
- 말씀과 함께하는 건강한 절제: 기본 · 16:8 · 다니엘 · 사순절 · 1일 금식 / 집중 감량 14·21일
- 기도와 헌신의 물 금식 (본인의 선택과 결단, 1·3·7·14·21·40일): 감량 예측 없음, 체중은 선택. 기간별(1, 3, 7, 14, 21, 40일) 몸의 변화·증상·위험·난이도·금기·회복식 길이, 성경 속 금식(모세·엘리야·예수님·에스더·느헤미야·요엘·이사야·마 6장), 40일 동안 날마다 다른 말씀+격려+기도(3·7·14·21·30·40일 특별 메시지), 회복식 중에도 말씀. 기존 잠금·확인란·문장 입력·의료 감독 확인·증상 체크·119·오늘 중단하기 그대로.
- 말씀 곳곳에: 물·식단·운동·체중·넘어졌을 때·저녁 돌아보기·토스트에 상황별 구절(날마다 바뀜).
- 나에게 맞는 길 (BMI 30 이상, 또는 '나'에서): GLP-1 기준 안내, 사용 중이면 의사와 함께하는 약물 자립 동행
